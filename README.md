# Stratagems Unleashed

A Helldivers 2 Lua mod (Bingus Shared Loader) that lets the Hellpod loadout take the same stratagem more than once,
vehicles included.

## Technical Description

- **Duplicates.** The loadout screen's stratagem list marks the stratagems already in the loadout as equipped, and a
  press on an equipped item is refused. While the list is open, the mod marks the loadout's stratagems back as
  selectable through the list's own marker function, so picking one again runs the game's normal equip: the
  slot is filled, synced to the lobby and saved like any pick. After such a pick the list's selection is cleared
  through the game's select function, since a press on the selected item plays no pick sound.
- **Vehicles.** The equip handler allows one mech, one FRV and one tank, using three kind bits in each stratagem's
  info flags. The mod clears those bits while the list is open and restores them when it closes, when the screen
  closes, or on any error, never overwriting a value the game changed meanwhile.
- **Multiplayer.** Only the local loadout is changed; it leaves through the game's own sync, so teammates need
  nothing.
- **Finding the game's code.** Every address and structure offset comes from 11 code signatures in game.dll
  (generated by `research/signatures.py`): the screen stack, stratagem table and offers table globals, the marker and
  select functions, and the offsets of the list, loadout blocks and flags, read from the matched instructions. Each
  signature is tried at the known build's address first, else game.dll's executable sections are searched over a few
  frames; a signature must match exactly once, repeated values must agree, and the list refresh must call the marker
  found on its own. Anything else turns the mod off and the loadout works as normal.
- **Memory access.** Reads and writes go through `ReadProcessMemory` / `WriteProcessMemory` on the game's own
  process, which fail instead of crashing on a bad address. Per frame it reads a few small spans into fixed buffers.
- **Status.** `%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\StratagemsUnleashed_STATUS.log`, first line = verdict.

Research notes: [NOTES.md](NOTES.md). The offline tests (`tests/`) and `research/signatures.py` need a game.dll dump,
which is not included.
